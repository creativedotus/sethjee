# Sethjee Restaurant & Cafe

Single-page restaurant website (menu, reservation, gallery, reviews, location).

## Run / deploy
- Open `index.html` in any browser, or
- Enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root).

## Gallery ("Taste With Your Eyes")
Click any photo to open it in a lightbox. Previous/next arrows, keyboard left/right arrows, swipe on mobile, photo counter and dish name; close with ✕, outside click or Esc.
